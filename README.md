
# Welcome Screen and Role Selection

## Running the code

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Production build:
   ```bash
   npm run build
   ```

## Mock Data and Reset

From Welcome screen:

1. `Load Full Mock Data` adds complete test data for all role flows.
2. `Clear All Data` resets app state and local storage.
